# Sofia Elsberg — Portfolio

Personal portfolio site, built with Next.js, TypeScript, Tailwind CSS, and Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Project structure

- `app/page.tsx` — the page layout and sections
- `components/` — presentational components (`Reveal`, `MacBook`, `Phone`, `Details`, `Photo`)
- `data/content.ts` — site copy: projects, timeline, skills
- `lib/motion.ts` — shared Motion animation variants
- `app/globals.css` — theme tokens and global styles (Tailwind CSS v4)

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — lint with ESLint
